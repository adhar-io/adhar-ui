# @adhar-ui/svelte

Svelte components for the Adhar UI design system. Compiled from Mitosis sources as Svelte SFC with `export let` props and `on:click` events.

## Usage

Generated Svelte components are in `src/generated/`. CVA style variants and utilities:

```ts
import { buttonVariants, cn } from '@adhar-ui/svelte';
```
